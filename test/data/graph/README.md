# Graph test inputs

`horse5.graph` is the dual graph of `../gts-boolean/horse5.gts`, a node for
each face and an edge for each pair of faces on an edge, in the format of
Jostle and the Graph Partitioning Archive: a line "nn ne", then for each
node the numbers of its neighbours, from 1. Made on 2026-10-11 with Python.
